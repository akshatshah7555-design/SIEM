# SentinelX Sample Dataset

- File: `sentinelx_sample_events_1500.csv`
- Event count: **1560**
- Format: CSV
- All data is synthetic and intended for demonstration/testing only.
- Columns: timestamp, username, source_ip, event, status, asset, details
- Includes normal background events and planted scenarios such as repeated failed logins followed by success, privilege changes, bulk data export, and security-setting changes.
- Use this dataset to test SentinelX's event filtering, detection rules, storyline correlation, and report export. Detection results depend on the exact rules implemented in your app.
